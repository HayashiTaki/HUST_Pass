# 0.1.3 验证记录

验证日期：2026-09-26。Microsoft Edge 153.0.4234.48。

## 本次行为变化

删除普通鼠标、键盘操作触发的自动停止逻辑，以及实验版的鼠标事件匹配器、登记和点击回执消息。激活流程只校验当前登录页和验证码框，发送一次浏览器级点击、断开调试器，再等待字段实际值就绪。重复事件或最终事件目标变化不再阻断流程。

学号密码变化会重置 800ms 稳定计时。识别期间编辑字段会延后提交并释放旧任务，仅回退当前未提交的尝试；已有验证码失败次数保留。明确的手动验证码输入、点击登录和 Enter 提交仍会阻止覆盖或重复提交。

扩展开关、离开页面、验证码失效、超时、网站错误和额外认证处理保留。权限和 OCR 算法不变。

## 检查范围

类型检查通过；29 项单元测试、14 项自动填充 Edge 场景和 17 项登录 Edge 场景全部通过。

- 类型检查和单元测试覆盖自动填充、任务失效、超时清理、凭据修改的尝试回退及重放保护。
- Edge 自动填充测试覆盖重复点击、普通点击和按键、BODY/父容器重定向、账号编辑、手动验证码、导航和标签页切换。
- Edge 登录流程测试覆盖请求中修改账号、OCR 运行中修改密码、无需点击重试的自动恢复，以及手动点击/Enter 提交后不重复登录。
- 最终测试数量和原始结果见随版本保存的 `autofill-browser-0.1.3.json` 与 `browser-0.1.3.json`。

测试使用独立浏览器配置、假凭据和原生 autofill 伪类模拟。真实账号认证与业务跳转未在开发测试中执行，不能将模拟通过表述为真实登录已验证。

以下保留 0.1.1 历史报告；其中手动操作策略已由上述 0.1.3 行为取代。

# 0.1.1 验证记录

验证日期：2026-09-26。浏览器：Microsoft Edge 153.0.4234.48；Node.js 24。

## 本次修复

0.1.0 只在学号、密码的 DOM `value` 非空时启动。0.1.1 增加原生自动填充状态识别：值尚不可读但字段匹配 `:autofill` / `:-webkit-autofill` 时，在当前前台认证页短暂连接调试器，向验证码框发送一次鼠标按下、释放，断开后等待值就绪，再进入原有 OCR 和登录流程。

每个文档最多激活一次，不消耗验证码尝试次数。新增的调试命令仅限鼠标按下、释放；没有读取密码、执行任意脚本或通用调试命令入口。

## 已完成

- `npm run typecheck`：通过。
- `npm test`：27 项通过，包含自动填充状态、超时后迟到连接清理、取消、遮挡、目标移动、过期文档、每页一次限制，以及原有验证码和重试状态机测试。
- `npm run test:autofill`：7 个 Edge 场景通过。模拟字段带原生 autofill 标记而 DOM 值为空；普通脚本点击不能填充，只有扩展发出的受信任鼠标事件才让测试凭据成为可读值。验证随后自动识别、填入验证码并点击登录，同时检查只连接和断开各一次。
- `npm run test:browser`：原有 13 个 Edge 场景通过，包含延迟填值、前导零、错误 MIME、离线 OCR、三次重试上限、手动接管、网络异常、额外认证、开关、多标签页及弹窗错误提示。
- `node scripts/live-smoke.mjs`：真实认证页基础地址及带 `service` 的地址均可正常检测。所有 POST 均被阻断；未提交真实登录。

自动填充测试还覆盖：实际空字段不激活、已经可读的值跳过调试、连接失败、点击后仍不可读的超时、显式重试不重复激活、手动输入及标签页切换。

## 测试边界

自动填充回归使用 DevTools `CSS.forcePseudoState` 设置浏览器原生伪类；字段值保持为空，直到收到真正的受信任鼠标事件才写入假测试凭据。这比初版直接设置 `.value` 的测试覆盖了更多行为，但仍是隔离模拟，**不能等同于使用 Edge 密码管理器中保存的真实账号完成登录**。真实账号认证和后续业务跳转仍需实际使用验证。

OCR 算法没有修改。沿用 2026-09-25 的独立 100 张样本验收结果：98 张正确、2 张拒识、0 张误识别，平均 89ms（Node.js，不含模型初始化）。此结果只描述样本集表现，不保证未来所有验证码。
